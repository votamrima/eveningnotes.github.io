`tlog` records terminal activity for auditing and troubleshooting.

### Install

```bash
dnf install -y tlog
```

### Create a test user

```bash
useradd audituser
passwd audituser
```

Set `tlog` as the login shell:

```bash
usermod -s /usr/bin/tlog-rec-session audituser
```

Check:

```bash
getent passwd audituser
```

Expected shell:

```text
/usr/bin/tlog-rec-session
```

### Generate a recording

Login as the user:

```bash
ssh audituser@servera
```

Run some commands:

```bash
whoami
pwd
ls -l
cat /etc/hostname
```

Then:

```bash
exit
```

### Find recordings

```bash
journalctl _COMM=tlog-rec-sessio
```

Filter by user:

```bash
journalctl _COMM=tlog-rec-sessio | grep audituser
```

Look for the recording ID:

```text
"rec":"<RECORDING_ID>"
```

### Replay a session

```bash
tlog-play -r journal -M TLOG_REC=<RECORDING_ID>
```

### Remember

```text
user login
   ↓
tlog-rec-session
   ↓
session stored in journal
   ↓
find recording ID
   ↓
tlog-play
```

By default, `tlog` mainly records terminal output; keyboard input such as passwords is not normally recorded.
